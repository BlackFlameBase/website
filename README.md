# Black Flame — Full Prototype v1

GitHub Pages-ready prototype of the six-page Black Flame website.

## Routes
- index.html — Home
- black-flame.html — canonical orientation page
- book.html — In Development state + Primer subscription gateway
- artchive.html — Creative Works archive prototype
- shop.html — Coming Soon state
- about.html — Origin/founders prototype

## Prototype boundary
This build has no authenticated CMS. Content is structured for later CMS integration. The Home content model remains in `content.js`; inner-page copy is currently in page markup and will be migrated into the production content model/CMS after visual approval.

## Audio
Place official audio at `assets/audio/black-flame.mp3` or update the source path later through the CMS.

## GitHub Pages
Upload the full folder contents while preserving `assets/`. GitHub Pages can serve the static prototype directly.
